# Security Policy

## Supported versions

Security fixes are provided for the latest released version.

## Reporting a vulnerability

Please report vulnerabilities privately through the repository's **Security** tab by selecting **Report a vulnerability**. Do not open a public issue for a suspected vulnerability.

Include the affected version, impact, reproduction steps, and any suggested mitigation. Do not include real AWS credentials, tokens, Account IDs, ARNs, or other sensitive data. You can expect an initial response within seven days.
